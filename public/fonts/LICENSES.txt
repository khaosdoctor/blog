Fonts served from this folder, and what each one obliges us to do.

Five of these are applied to the site: Departure Mono (the default face, and every
header, button and control), PxPlus IBM VGA8 (subtitles), Literata (body text),
Atkinson Hyperlegible (the settings panel's other reading font) and Cascadia Code
(code blocks). The rest are still served because the archived bench at
/theme-lab-arquivo/ renders every one of them at a real size, so deleting a file
costs that page a specimen. A licence note only leaves here when its font file does.
