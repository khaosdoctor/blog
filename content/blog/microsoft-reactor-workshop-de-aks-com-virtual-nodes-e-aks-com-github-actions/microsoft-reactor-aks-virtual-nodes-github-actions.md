On the 29th I participated in an amazing live stream from Microsoft Reactor with [Caio Calado](https://www.linkedin.com/in/caiocaladoo/) as host!

In this live stream we did a hands-on workshop on how we can create a cluster in [Azure Kubernetes Service](https://docs.microsoft.com/azure/aks/?WT.mc_id=blog-personal-ludossan) and harness the power of Virtual Nodes for infinite scalability, that's our first demonstration.

Then we moved on to practically create a repository on GitHub to use GitHub Actions so we could build and deploy complete applications to [AKS](https://docs.microsoft.com/azure/aks/?WT.mc_id=blog-personal-ludossan) without even needing to touch them

You can find all of this for free in the video below!
