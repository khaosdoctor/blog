Today I participated in the **Meetrybe**, the first online event from [**Trybe**](https://betrybe.com) together with a bunch of heavyweights like: [Elton Minetto](https://twitter.com/eminetto), [Rogério Munhoz](https://twitter.com/roziscoding) and [Igor Halfeld](https://twitter.com/igorhalfeld).

After amazing talks from Elton and [Ana Cardoso](https://www.youtube.com/redirect?redir_token=QUFFLUhqa05peURIMk9MZkRPN2dKZVU5MmlGRnJ3QkxtQXxBQ3Jtc0tra1VSd1hHLWRpWkthYmpmY1JtRk83b3o3MUFLTUdPdF9lalA0QWdRSFFWdU9DMWRVYy1LZkZaNE1ELTA2ckNqM2hlSnlGUUVZdldFbDZiazdpS2lVM0p6c2pPVTBEbnR2WnpOM0dRYVRWVFJMUmpKcw%3D%3D&q=https%3A%2F%2Fwww.linkedin.com%2Fin%2Fcardosoanacp%2F&v=3fmUp3PICLo&event=video_description), we set up a Q&A session about software architecture. We cleared up several really cool questions and even created some iconic phrases like:

> Every legacy was once hype

It was a super relaxed conversation! Check out how it went!
